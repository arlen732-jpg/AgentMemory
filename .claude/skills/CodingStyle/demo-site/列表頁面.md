# 列表頁面

**定義**：顯示某一集合的資料，附篩選、搜尋、三態（載入、空、無結果），點一筆開抽屜修改。

## 骨架

情境：所有列表頁都長一樣，讀者看一頁就會用其他頁。

```tsx
"use client";
const ALL = "__all__";

export default function MemoriesPage() {
  const [memories] = useCollection("memories");
  const [q, setQ] = useState("");
  const [editing, setEditing] = useState<Memory | "new" | null>(null);

  const filtered = useMemo(() => (memories ?? []).filter(…).sort(…), [memories, q]);
  const filtering = q.trim() !== "";

  return (
    <>
      <PageHeader title="記憶" description="…" actions={<Button onClick={() => setEditing("new")}>新增記憶</Button>} />
      <Card className="mb-6">{/* 篩選列 grid */}</Card>

      {memories === null ? <Skeleton /> :
       filtered.length === 0 ? <Card><EmptyState … /></Card> :
       <ul className="grid gap-4 md:grid-cols-2 xl:grid-cols-3">…</ul>}

      <MemoryDrawer open={editing !== null} memory={editing === "new" ? null : editing} onClose={() => setEditing(null)} />
    </>
  );
}
```

## 重點

- `editing` 用三態：`null` 關閉、`"new"` 新增、物件為修改。新增與修改共用同一個抽屜。
- **空狀態分兩種**：有篩選時顯示「找不到符合的…」＋「清除篩選」；沒資料時顯示「還沒有任何…」＋主要 CTA。禁止留白。
- 下拉「全部」用 `ALL = "__all__"` 常數，不用空字串（避免與真實值混淆）。
- 篩選列手機一欄、`sm:` 以上用 `grid-cols-[1fr_10rem_10rem]`。
- 列表上方顯示 `共 N 筆`（`data-testid="{功能}-count"`）。

## 三種呈現方式

依資料性質選一種，不要混用：

| 資料性質 | 呈現 | 頁面 |
|---|---|---|
| 文字為主、欄位不固定 | 卡片 grid（`md:grid-cols-2 xl:grid-cols-3`） | 記憶 |
| 數字欄位要對齊比較 | 表格，外層 `overflow-x-auto` + `min-w-[..rem]`，數字欄 `text-right` | 血壓、通行碼 |
| 依日期分批發生 | 依台北日期分組的卡片，每組一個 `Card className="p-0"` | 吃藥 |

表格整列可點時，列上加 `onClick`，第一欄另放一個 `<button>` 給鍵盤使用者（`e.stopPropagation()` 避免觸發兩次）。

## 期間篩選

健康紀錄共用 `PeriodFilter`（7／30／90 天／自訂），用 `periodRange()` 換成 ISO 起迄，再用字串比較篩選：

```tsx
const [from, to] = periodRange(period);
rows.filter((r) => r.measuredAt >= from && r.measuredAt <= to)
```

⚠️ 注意：字串比較能成立，是因為所有時間都存成 `toISOString()` 的 UTC 格式。混入 `+08:00` 格式的字串就會比錯（mock 的 memories `updatedAt` 是 +08:00，只用來排序，不做期間比較）。
