## 技術棧

| 項目 | 版本／選擇 |
|---|---|
| 框架 | Next.js 16.4（App Router） |

## 元件宣告

頁面與互動元件用 `"use client"` + `export default function`，props 直接在參數寫型別，不另開 interface。

```tsx
"use client";
export default function MemoryDrawer({ open, memory, onClose }: { open: boolean; memory: Memory | null; onClose: () => void }) {
```

⚠️ 注意：TS 外掛會對 `onClose` 這類函式 props 提示「Props must be serializable」。只在 client 元件間傳遞時可忽略，不要改名成 `xxxAction`。

## 資料存取：useCollection

頁面只透過 `useCollection(name)` 讀寫，不直接碰 sessionStorage。正式版換成 API 時，頁面不必改。

```tsx
const [memories, api] = useCollection("memories");
// memories === null 代表 SSR／水合中 → 顯示 <Skeleton />
api.add({ ...row, id: newId() });
api.update(id, patch);
api.remove(id);
```

## 樣式

- 卡片：`rounded-md bg-surface p-5 shadow-sm`，可點的卡片加 `hover:-translate-y-px hover:shadow-md`。
- 過場時間用 token：`duration-[var(--duration-base)]`。
- 觸控目標至少 44px：按鈕、輸入框用 `min-h-11`。
- 主色文字用 `text-primary-text`，不要用 `text-primary`（對比不足）。
- 圖片外框加 `img-fallback`，圖未到位時顯示漸層。

## 日期時間

一律透過 `lib/dates.ts`，業務時區固定 +8。

```ts
fmtDate(iso)        // 2026/11/12
fmtDateTime(iso)    // 2026/11/12 07:30
toLocalInput(iso) / fromLocalInput(v)   // <input type="datetime-local"> 互轉
```

## 列舉值

```ts
export const TOKEN_STATUS = { ACTIVE: "active", EXPIRED: "expired", REVOKED: "revoked" } as const;
export const TOKEN_STATUS_LABEL: Record<TokenStatus, string> = { active: "有效", … };
```

狀態能推導的就不存欄位（例：通行碼狀態由 `revokedAt`、`expiresAt` 推導）。

## 連結按鈕

看起來像按鈕的導頁連結用 `LinkButton`（下載檔加 `download`）。

```tsx
<LinkButton href="/memories/import" variant="secondary" data-testid="memories-import-link">匯入</LinkButton>
```

⚠️ 注意：不要寫 `<Link><Button/></Link>`，那會產生巢狀互動元素，鍵盤要按兩次 Tab。

## 無障礙

- 圖示按鈕用 `IconButton`，必給 `label`。
- 錯誤訊息 `role="alert"`；輸入框 `aria-invalid`。
- 對話框 `role="dialog"`／`"alertdialog"` + `aria-modal`。
