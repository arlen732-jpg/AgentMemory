# 表單抽屜

**定義**：新增／修改單筆資料的表單，放在 `Drawer` 中，含驗證、儲存結果跳窗、刪除確認。

## 骨架

```tsx
export default function XxxDrawer({ open, record, onClose }: { open: boolean; record: Xxx | null; onClose: () => void }) {
  const [all, api] = useCollection("xxx");
  const dialog = useDialog();
  const [form, setForm] = useState<XxxInput>(empty);
  const [errors, setErrors] = useState<Errors<keyof XxxInput>>({});

  // 每次打開時重設表單（不靠 key 重掛）
  useEffect(() => { if (open) { setForm(record ? toInput(record) : empty()); setErrors({}); } }, [open, record]);

  const handleSave = async () => {
    const e = validateXxx(form, all ?? [], record?.id);
    setErrors(e);
    if (hasErrors(e)) { await dialog.notify({ ok: false, title: "儲存失敗", message: "…請依紅字修正後重新儲存。" }); return; }
    const row = { …trim 後的欄位 };
    record ? api.update(record.id, row) : api.add({ ...row, id: newId() });
    await dialog.notify({ ok: true, title: "已儲存", message: "…" });
    onClose();
  };
```

## 重點

- **驗證放 `lib/validation.ts`**，回傳 `Errors<欄位>` 物件；頁面只負責顯示。理由：匯入頁、AI 工具（正式版）要共用同一套規則。
- 唯一性檢查傳 `excludeId`，修改時排除自己。
- **儲存前一律 `.trim()`**。
- 驗證失敗也要跳窗（DevGuidelines：送件結果不論成敗都跳窗），紅字留在欄位下方。
- 欄位用 `<Field label required htmlFor error hint>` 包 `TextInput`／`TextArea`／`Select`；`id` 與 `htmlFor` 一致，錯誤訊息的 testid 自動為 `{id}-error`。
- 有字數限制的欄位在 `hint` 顯示 `已輸入 / 上限`。
- footer：修改時左側放刪除（`variant="ghost"` + `text-danger` + `mr-auto`），右側「取消」「儲存」。
- 時間欄位用 `<TextInput type="datetime-local">`，載入用 `toLocalInput()`、儲存前用 `fromLocalInput()`；`max` 設現在，驗證再擋一次「不可晚於現在」。
- 數字欄位用 `inputMode="numeric"`，`onChange` 先 `replace(/\D/g, "")`，表單狀態存字串，驗證通過才 `Number()`。
- 自動完成用原生 `<datalist>`（例：藥名），不另引套件。
- 撤銷這類「不是刪除但不可逆」的動作用 `dialog.confirm({ danger: true })`，不用輸入「刪除」。
- 刪除：`await dialog.confirmDelete({ target: "記憶「上班時間」" })` → 刪 → `notify` → `onClose()`。
